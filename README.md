# Omarchy Shell Plugins

Plugins for the [Omarchy](https://omarchy.org/) shell. Each folder is a standalone plugin that also lives in its own repo, so each can be installed and updated independently.

| Plugin                              | Kind                | Description                                                                  |
| ----------------------------------- | ------------------- | ---------------------------------------------------------------------------- |
| [Focusd](focusd/)                   | bar-widget          | Focusd pomodoro timer with a control panel                                   |
| [Media](media/)                     | service, bar-widget | MPRIS now-playing with playback controls (clone of built-in `omarchy.media`) |
| [Obsidian Search](obsidian-search/) | overlay             | Fuzzy-search your Obsidian vault                                             |
| [Readest](readest/)                 | overlay             | Fuzzy-search your Readest library                                            |
