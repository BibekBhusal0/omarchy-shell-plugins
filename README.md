# Omarchy Shell Plugins

Plugins for the [Omarchy](https://omarchy.org/) shell. Each folder is a standalone plugin that also lives in its own repo, so each can be installed and updated independently.

| Plugin                              | Kind                | Description                                                                          | Repo                                                                            |
| ----------------------------------- | ------------------- | ------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------- |
| [Focusd](focusd/)                   | service, bar-widget | Focusd pomodoro timer with a control panel                                           | [omarchy-focusd](https://github.com/BibekBhusal0/omarchy-focusd)                 |
| [Better Lock](lock/)                | service             | Lock screen with date/time, media, power controls (clone of built-in `omarchy.lock`) | [omarchy-better-lock](https://github.com/BibekBhusal0/omarchy-better-lock)       |
| [Better Media](media/)              | service, bar-widget | MPRIS now-playing with playback controls (clone of built-in `omarchy.media`)         | [omarchy-better-media](https://github.com/BibekBhusal0/omarchy-better-media)     |
| [Better Menu](menu/)                | menu, bar-widget    | Fuzzy menu with app grid, calculator and search (clone of built-in `omarchy.menu`)   | [omarchy-better-menu](https://github.com/BibekBhusal0/omarchy-better-menu)       |
| [Obsidian Search](obsidian-search/) | overlay             | Fuzzy-search your Obsidian vault                                                     | [omarchy-obsidian-search](https://github.com/BibekBhusal0/omarchy-obsidian-search) |
| [Readest](readest/)                 | overlay             | Fuzzy-search your Readest library                                                    | [omarchy-readest](https://github.com/BibekBhusal0/omarchy-readest)               |
| [Youtube Video Downloader](ytdl/)   | service, bar-widget | yt-dlp video downloads with progress and history                                     | [omarchy-ytdl](https://github.com/BibekBhusal0/omarchy-ytdl)                     |
