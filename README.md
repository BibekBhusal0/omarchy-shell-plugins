# Omarchy Shell Plugins

Plugins for the [Omarchy](https://omarchy.org/) shell. Each folder is a standalone plugin that also lives in its own repo, so each can be installed and updated independently.

| Plugin                              | Kind                | Description                                                                   |
| ----------------------------------- | ------------------- | ----------------------------------------------------------------------------- |
| [Focusd](focusd/)                   | bar-widget          | Focusd pomodoro timer with a control panel                                    |
| [Better Lock](lock/)              | service             | Lock screen with date/time, media, power controls (clone of built-in `omarchy.lock`) |
| [Better Media](media/)            | service, bar-widget | MPRIS now-playing with playback controls (clone of built-in `omarchy.media`)  |
| [Better Menu](menu/)              | menu, bar-widget    | Fuzzy menu with app grid, calculator and search (clone of built-in `omarchy.menu`) |
| [Obsidian Search](obsidian-search/) | overlay             | Fuzzy-search your Obsidian vault                                              |
| [Readest](readest/)                 | overlay             | Fuzzy-search your Readest library                                             |
| [Youtube Video Downloader](ytdl/)                       | service, bar-widget | yt-dlp video downloads with progress and history                              |
